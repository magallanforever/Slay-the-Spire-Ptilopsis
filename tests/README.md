# Tests

## 医者·典训

游戏内检查：

- 新开白面鸮：神经冲击 3 张、记忆防线 3 张、启动线程 1 张、只读线程 1 张、医者·典训 1 张，共 9 张。
- 神经冲击为 6 点伤害，升级 9 点；记忆防线为 5 点格挡，升级 8 点。
- 医者·典训为 1 费基础攻击：先施加 1 层易伤，再结算基础 4 点伤害，最后创建固定线程；没有构造伤害。
- 无其他修正时，新施加的易伤使这次攻击造成 6 点伤害；敌人有 1 层人工制品时，易伤被抵消，造成 4 点伤害。
- 普通线程回合结束打出基础群伤 3 的诊疗脉冲，析构打出基础群伤 6 的诊疗脉冲；分别计算各敌人的易伤与格挡。
- 升级后为 2 层易伤、基础攻击 5、函数群伤 4、析构群伤 8；悬停预览和实际效果一致。
- 满栏位时先析构最早的线程；新线程不可移除或替换函数。
- 神经冲击、记忆防线的初始数量不变。已有存档的牌组不会自动补入新牌。

这个目录目前放轻量级本地检查脚本。

## run-source-smoke.ps1

执行 Maven 编译，并确认关键类能从 `src/main/java` 重新生成：

```powershell
./tests/run-source-smoke.ps1
```

它不会启动游戏，也不会复制 jar 到游戏目录；完整打包仍使用：

```powershell
mvn package
```

## run-source-private-key-tests.ps1

编译工程后执行源私钥估价测试：

```powershell
./tests/run-source-private-key-tests.ps1
```

覆盖致命攻击、无实体、格挡、抽牌限制、符文金字塔、长期能力收益，以及候选牌排序和去重。
评分规则集中在 `SourcePrivateKeyEvaluator` 的候选表中；新增候选时，在同一表中添加卡牌 ID 和估价函数。

游戏内另需验证：使用源私钥出现三张候选牌；选择后入手且本回合为 0 费；保留到下回合恢复费用；满手牌时进入弃牌堆；神圣树皮使所选牌获得两份；使用后战斗正常继续。

## run-card-review-tests.ps1

```powershell
./tests/run-card-review-tests.ps1
```

验证归并排序按真实抽牌顺序统计逆序对、优先抽到低费牌，并保持同费牌顺序。
同时检查源码卡牌 ID 对应的中英文名称、描述、所需升级描述，以及卡面上的自定义关键词引用。关键词统一在各语言的 `keywords.json` 中维护。
此脚本不启动游戏；卡面排版、悬停提示和战斗中的线程触发仍需游戏内验证。

## 手动挂载与平衡调整

游戏内检查：

- 新开白面鸮时初始遗物为莱茵生命工牌；每场战斗开始得到 1 个空可变线程，另有 2 个空栏位。
- 移除工牌或通过涅奥替换初始遗物后，战斗开始不再由工牌生成线程。

- 启动线程打出后进入消耗堆，升级后仍消耗。
- 1 点能量时确认挂载，能量变为 0，原牌仍在手中。
- 不选牌直接确认时，不扣能量，也不挂载。
- 0 点能量点击空可变线程时提示能量不足。
- 移除函数免费，重新挂载再收取 1 点能量。
- 脑啡肽在 0 点剩余能量时仍能自动挂载并抽牌。
- 敌人回合、动作结算中、目标线程被移除时不能手动挂载。
- 卡牌及其升级版、固定线程效果使用调整后的数值。

挂载消耗牌或能力牌时另需检查：

- 手动挂载、脑啡肽自动挂载：回合结束执行牌效后析构，留下空栏位，原牌不受影响。
- 普通牌不会自动析构；快速迭代赋予的消耗也会使线程自动析构。
- 能力牌结算后线程自动析构，已获得的能力继续生效。
- 回合中激发不会提前析构；回合结束等待已排队的牌效执行完毕。
- 移除或更换函数后，旧函数不会导致新函数所在的线程自动析构。
- 只读线程等固定线程不因生成它的牌带有消耗而自动析构。

## 线程卡牌预览与出牌结算

以下检查需要进入游戏，编译检查不代表这些交互已通过：

- 悬停已挂载的线程，显示原牌复制品；悬停只读线程，显示“缓存屏障”，卡图为战士打击，描述为获得格挡。
- 唤醒例程显示“唤醒信号”，标明回合开始；回合结束不额外抽牌。
- 离线封装多张牌后，滚轮按封装顺序切换预览；移开鼠标后关闭预览。空线程仅显示挂载提示。
- 预览不改变原牌的数值、费用或升级状态；窗口边缘、不同分辨率下卡牌不出屏，管理菜单不被遮挡。
- 固定线程的构造、函数、激发、析构均打出临时效果牌；出牌计数及适用的能力、遗物正常触发，临时牌不留在牌堆中。
- 只读线程为基础版且敏捷为 2 时，缓存屏障预览和实际获得的格挡均为 5，敏捷只计一次。
- 单个线程配合升级超线程时，左右各触发一次，再执行正常回合结束函数，共三次。离线的每次触发均完整保留封装顺序。
- 挂载协程让渡等触发牌不会递归触发自身；离线打出结晶梦境时仍正常结算自己的析构格挡。
- 挂载消耗牌或能力牌时，等待全部已排队复制品结算后析构；原牌保留，能力继续生效。
- 战斗胜利后，不继续出牌；新战斗没有旧线程预览或待结算的效果牌。
