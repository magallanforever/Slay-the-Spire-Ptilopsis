# Tests

## 赫默与取消挂载

- 赫默为 2 费罕见能力。每层能力在回合开始时依次进行两轮三选一，随后将两张牌按选择顺序挂载进同一个新可变线程，免费且不加入手牌。
- 升级仍为 2 费，打出时立即额外执行一轮完整流程；已有多层赫默也只额外执行一次。
- 候选来自本局本职业普通、非罕见和罕见牌池，排除 HEALING 标签的牌；缪尔赛斯带此标签。每组三张不同，第二组重新随机，可与第一组重复。
- 始终创建新线程，不覆盖已有可变线程的函数；栏位已满则正常析构最早的线程。
- 悬停滚轮切换两张预览；回合末按顺序出牌。任一张为能力或消耗牌时，等待两张牌结算后析构整条线程。
- 已挂载线程不可手动卸载，点击不打开菜单；空可变线程仍能花费 1 能量挂载。脑啡肽的自动替换规则不变。
- 实机检查连续选牌、赫默叠层、升级立即触发、选到赫默后的能力叠加，以及战斗结束后没有遗留选牌界面。
- `run-thread-combat-tests.ps1` 使用模拟选牌界面验证两轮选择、候选去重与治疗牌过滤、新建双牌线程、预览隔离及升级立即触发。实际选牌界面的输入和显示仍需实机验证。

## 血脑屏障与线程状态栏

- 血脑屏障：2 费蓝卡技能，不消耗；立即结算各存活敌人的主定理，以实际总伤害获得一次格挡。
- 升级先给所有敌人 3 层主定理；等待人工制品等效果结算后再读取层数。没有主定理的敌人不造成伤害。
- 结算沿用主定理的生命流失类型，不受敌人格挡、虚弱或易伤影响；伤害减免按原生伤害结算，格挡读取实际伤害。
- 格挡不另加敏捷或计算脆弱，钙质化等获得格挡时的效果仍生效；立即结算后层数减半、向上取整，Hack it! 可阻止。敌人回合结束的正常衰减不变。
- 线程不再注册为玩家能力，血条下方不显示线程图标、数字或提示；充能球位置的线程、挂载选牌和预览保持正常。
- 检查超线程、协议并发、协程让渡、结晶梦境及线程数量相关卡牌；新战斗不能残留旧线程。

## 梯度下降

- 1 费普通技能，不消耗，构造固定线程；构造时不施加主定理。
- 回合结束给一个随机存活敌人 4 层主定理，析构给所有存活敌人各 4 层；升级后两处均为 6 层。
- 悬停显示梯度迭代，数值与线程一致；所有效果通过临时技能牌结算，人工制品正常抵消主定理。
- 协议并发触发随机单体效果；协程让渡触发群体效果但保留线程；溢出栏位或结晶梦境真正析构时也触发群体效果。
- 临时效果牌不进入奖励卡池；战斗结束或没有存活敌人时不继续出牌。

## 内存泄漏

- 蓝卡技能，1 费，保留；先抽 3 张牌，再将自身复制品加入手牌，不消耗。
- 升级后 0 费、抽 2 张，复制品同样升级且保留；再次升级不改变数值。
- 抽牌后满手时，复制品按原生规则进入弃牌堆；无法抽牌时仍生成复制品。
- 挂载后正常免费重放，但未升级版本生成的手牌不会继承线程的免费打出标记。

## 协议并发

- 协程让渡为 2 费，升级后仍为 0 费，保留消耗和触发析构效果的行为。
- 协议并发为 1 费普通技能，升级后 0 费，不消耗；所有线程的回合结束效果各触发一次。
- 不触发回合开始或析构效果，不提前移除挂载消耗牌或能力牌的线程；真正回合结束时仍按原规则结算和析构。
- 游戏内检查：挂载协议并发或在离线中封装它时，不得递归无限出牌；空线程无效果，唤醒例程不额外抽牌。

## 塞蕾娅、钙质化与析构

- 塞蕾娅：2 费罕见攻击，7 点伤害三次，击晕目标，构造钙质化；升级为 9 点三次和钙质化+。
- 击晕跳过敌人下一次行动，之后恢复原意图；人工制品可以抵消击晕，不影响生成线程。敌人的回合能力仍正常结算。
- 钙质化存在时，每次实际获得正数格挡额外 +1。多个钙质化叠加；升级不增加这项加成。0 格挡不触发。
- 普通钙质化的函数为获得 3 点格挡，升级为 5 点。只有一个钙质化且无其他修正时，实际获得 4/6 点。
- 析构最后一个钙质化时，10 格挡变为 20。仅触发其析构效果并保留线程时，翻倍获得的格挡仍受常驻加成影响，10 变为 21。
- 协程让渡触发所有析构效果，但不移除线程：只读线程抽牌、唤醒例程回能抽牌、医者·典训群伤、离线获得格挡、钙质化翻倍格挡。空线程和无析构效果的可变线程不额外执行函数。
- 超线程同样只触发析构效果；升级后仅有一个线程时触发两次，该线程继续存在。
- 离线被触发析构效果后，保存的牌和后续回合的重放保持正常；真正析构才清理保存内容。

## run-thread-combat-tests.ps1

先运行 Maven 编译，再执行 `./tests/run-thread-combat-tests.ps1`。
测试加载本地游戏 JAR，模拟图形接口并跳过角色的图形构造，不打开游戏窗口，不读取或保存玩家存档。
覆盖原生伤害计算中的虚弱、易伤、目标切换和群体伤害，钙质化叠加与移除，以及析构效果与移除线程的区别。另检查击晕跳过行动、恢复意图且不覆盖转阶段动作。
线程生命周期测试覆盖构造、挂载、满栏析构且不注册玩家能力。血脑屏障使用模拟受伤目标检查总伤害转格挡、即时衰减、Hack it! 和零伤害；完整伤害钩子与升级版人工制品交互仍需实机检查。
这不是 ModTheSpire 完整运行测试，补丁注入、意图显示和动画仍需在游戏内验证。

挂载伤害还需游戏内检查：挂载基础伤害 8 的牌，虚弱时造成 6；目标有易伤时造成 9；换成无易伤目标仍为 6。
移除状态后回到 8，群伤逐个计算易伤。只剩 1 回合虚弱时，回合结束的线程出牌仍受虚弱影响，且正常函数只执行一次。

## 手动挂载与平衡调整

游戏内检查：

- 新开白面鸮时初始遗物为莱茵生命工牌；每场战斗开始得到 1 个空可变线程，另有 2 个空栏位。
- 线程按创建顺序入队；满栏时析构队首。消耗牌或能力牌所在的线程到期后只析构自身，其余线程前移，空栏位留在末尾。
- 入队使用原生 `channelOrb()`；满栏时由原生动作队列先析构、再入队。构造效果在实际入栏后触发，无栏位时不触发。
- 移除工牌或通过涅奥替换初始遗物后，战斗开始不再由工牌生成线程。

- 启动线程不消耗，升级后仍可反复使用。
- 扩容是非罕见能力牌，不在初始牌组中；保留原版插画与效果，增加 2 个线程栏位，升级后增加 3 个。
- 1 点能量时确认挂载，能量变为 0，原牌仍在手中。
- 不选牌直接确认时，不扣能量，也不挂载。
- 0 点能量点击空可变线程时提示能量不足。
- 已挂载线程不可手动卸载，点击不会扣能量或改变函数。
- 脑啡肽在 0 点剩余能量时仍能自动挂载并抽牌。
- 脑啡肽叠层后，每回合前若干张主动打出的牌依次触发；当回合新增层数立即增加可触发次数，线程自动出牌不占次数。
- 敌人回合、动作结算中、目标线程被移除时不能手动挂载。
- 卡牌及其升级版、固定线程效果使用调整后的数值。

挂载消耗牌或能力牌时另需检查：

- 手动挂载、脑啡肽自动挂载：回合结束执行牌效后析构，留下空栏位，原牌不受影响。
- 普通牌不会自动析构；快速迭代赋予的消耗也会使线程自动析构。
- 能力牌结算后线程自动析构，已获得的能力继续生效。
- 仅触发析构效果不会提前移除线程；回合结束等待已排队的牌效执行完毕。
- 自动替换函数后，旧函数不会导致新函数所在的线程自动析构。
- 只读线程等固定线程不因生成它的牌带有消耗而自动析构。

## 线程卡牌预览与出牌结算

以下检查需要进入游戏，编译检查不代表这些交互已通过：

- 悬停已挂载的线程，显示原牌复制品；悬停只读线程，显示“缓存屏障”，卡图为战士打击，描述为获得格挡。
- 唤醒例程显示“唤醒信号”，标明回合开始；回合结束不额外抽牌。
- 离线封装多张牌后，滚轮按封装顺序切换预览；移开鼠标后关闭预览。空线程仅显示挂载提示。
- 预览不改变原牌的数值、费用或升级状态；窗口边缘、不同分辨率下卡牌不出屏。
- 固定线程的构造、函数、析构效果均打出临时效果牌；出牌计数及适用的能力、遗物正常触发，临时牌不留在牌堆中。
- 只读线程为基础版且敏捷为 2 时，缓存屏障预览和实际获得的格挡均为 5，敏捷只计一次。
- 单个线程配合升级超线程时，执行两次析构效果和一次正常回合结束函数。离线的函数按封装顺序重放，析构效果只获得格挡。
- 普通超线程与超线程+独立叠层。各一层时，左侧析构效果触发 2 次、右侧 1 次；只有一个线程时共触发 3 次，与出牌顺序无关。
- 快速迭代生成的牌显示“消耗”；入手和再次复制后仍为 0 费并保留消耗，挂载后会使线程在回合结束结算后析构。
- malloc 是 X 费普通技能，构造 X 个空可变线程并消耗；升级后，原始 X 至少为 1 时获得 1 点能量。化学物 X 额外构造 2 个线程，但不改变返能门槛；免费打出不扣能量。
- 挂载协程让渡不会递归打出自身；离线打出结晶梦境时仍正常结算自己的析构格挡。
- 挂载消耗牌或能力牌时，等待全部已排队复制品结算后析构；原牌保留，能力继续生效。
- 战斗胜利后，不继续出牌；新战斗没有旧线程预览或待结算的效果牌。
